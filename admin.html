Repository storage

How do you want to replace files?

Scope it to this one repository with Contents: Read and write only.

Token risk — read this. The token is held in sessionStorage and is erased when you close this tab. It is never written to localStorage and never committed to the repo. Even so, a browser-held write token can be read by any script on this origin, so only use a fine-grained token limited to this single repository, and revoke it when you have finished. Never paste a classic token with broad scopes.

Account Security

Change the Superadmin password for this browser.

Fixed by design — the username cannot be renamed, replaced, or deleted.

Change password

At least 12 characters, including letters and numbers. Special characters are encouraged.

What this prototype can and cannot do. It can: enforce a fixed username, hash the password with PBKDF2-SHA-256 before storing it, rate-limit repeated attempts, and expire the session when the tab closes. It cannot: stop anyone who opens DevTools. Real protection needs server-side authentication, server-side hashing, HTTP-only session cookies, and access control.
